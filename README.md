# Công cụ tính thưởng Target QL / Trưởng ca

Website tĩnh chạy trực tiếp bằng GitHub Pages, không cần máy chủ.

## Điểm mới

- Hai ô `% HT Target doanh thu` và `% HT Target LNTT` để trống mặc định.
- Người dùng chọn được 6 giao diện màu.
- Người dùng chọn được 6 kiểu font chữ.
- Lựa chọn giao diện và dữ liệu được lưu riêng trên trình duyệt.
- Tính quỹ thưởng QL, Trưởng ca và phân bổ theo giờ công.
- Xuất JSON, CSV và in/PDF.

## Đưa lên GitHub Pages

1. Tạo repository mới trên GitHub.
2. Upload `index.html`, `styles.css`, `app.js` và `README.md` vào thư mục gốc.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn nhánh `main` và thư mục `/ (root)`.
6. Bấm **Save**.

Link sử dụng sẽ có dạng:

`https://TEN-TAI-KHOAN.github.io/TEN-REPOSITORY/`

## Lưu ý

Dữ liệu chỉ lưu trên thiết bị/trình duyệt của từng người. GitHub Pages không có cơ sở dữ liệu dùng chung.
