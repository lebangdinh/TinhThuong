# Hệ thống tính thưởng Target QL / Trưởng ca

Website tĩnh chạy trực tiếp trên GitHub Pages.

## Giao diện mặc định

- Theme: **HCH Cyan**
- Font: **Be Vietnam Pro**
- Hai ô `% HT Target doanh thu` và `% HT Target LNTT` để trống khi mở lần đầu.

## Đưa lên GitHub Pages

1. Upload toàn bộ `index.html`, `styles.css`, `app.js` và `README.md` vào thư mục gốc của repository.
2. Vào **Settings → Pages**.
3. Chọn **Deploy from a branch**.
4. Chọn branch `main`, thư mục `/ (root)` rồi bấm **Save**.

Đường dẫn thường có dạng:

`https://TEN-TAI-KHOAN.github.io/TEN-REPOSITORY/`

## Lưu ý

Dữ liệu nhập và lựa chọn giao diện được lưu trong `localStorage` của trình duyệt từng người. Website không gửi dữ liệu lên máy chủ.
